Clustering

Clustering requires at least three selected samples. Virtitta collects each sample's 15% IUPAC consensus FASTA and prepares the sequences using the configured 5′ and trailing poly-T trimming.

MAFFT aligns the prepared sequences. IQ-TREE then estimates a maximum-likelihood tree from that alignment. This is a phylogenetic analysis; interpretation still depends on sequence quality, sampling, and appropriate epidemiological context.

The result page reports job progress and provides the input, prepared FASTA, alignment, Newick tree, metadata, command settings, and log. When configured, Open GrapeTree sends the tree and metadata to GrapeTree for visualization.

Duplicate FASTA identifiers stop the normal action. The explicit “allow duplicates” action makes duplicated identifiers unique by adding their run names.

Distance matrices

Distance analysis requires at least two samples and both the 15% IUPAC and majority consensus FASTAs. Virtitta applies identical trimming and uses one MAFFT alignment to establish the shared gap pattern. It does not run IQ-TREE or GrapeTree.

For each pair, a position is compared only when both samples have at least 1× read coverage and valid IUPAC bases. Compatible IUPAC bases match. Substitutions count individually, while a supported internal gap block counts as one indel event; terminal and unsupported gaps are ignored.

  • Counts shows substitutions plus indel events. Details separates them and shows the pair-specific bases compared.
  • 15% IUPAC and Majority consensus select the consensus representation.
  • UPGMA reorders rows and columns to pull similar samples together for visual review. It does not change the values and is not a phylogenetic result.
  • A grey -1 means the pair had no eligible bases to compare.

These are coverage-supported, event-like minimum differences—not transmission distances or phylogenetic branch lengths.
